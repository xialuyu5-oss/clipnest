# ClipNest v1.3.0 — Web download controls

Web component notes for the deployment packages included with the [v1.4.0-alpha.1 source preview](v1.4.0-alpha.1.md). The Web application version remains v1.3.0; a separate v1.3.0 Git tag or Release is not implied.

Built with **OpenAI Vibe Coding**, using ChatGPT and Codex under user direction. Independent project; not an official OpenAI product.

## Web build outputs

| File | Purpose |
| --- | --- |
| `clipnest-v1.3.0-web.zip` | Web/Python deployment package; convenient for Windows extraction |
| `clipnest-v1.3.0-web.tar.gz` | The same application payload in tar.gz format |
| `SHA256SUMS.txt` | SHA-256 checksums for archives and the manifest |
| `release-manifest.json` | Payload filenames, sizes and hashes; explicit runtime/mobile/image inclusion flags |

These are the Web builder outputs. The combined prerelease uses `publication-manifest.json` and a combined checksum file, as listed in its notes.

Both archives include 31 deployment files: backend, browser assets, environment example, startup scripts, dependency declarations, optional Docker recipe, installation instructions and MIT license. System runtimes must be installed separately. This is not a self-contained executable or a prebuilt Docker image.

GitHub's automatically generated source archives are separate from these deployment assets.

## Changes

- Narrow-window controls retain usable sizes and wrap instead of clipping labels.
- Confirm duration, expected size and indicative time before downloading.
- Show live remaining-time estimates with explicit overall/current-track scope.
- Pause/resume supported sources and delete task cache on cancellation.
- Persist jobs and ready files across restarts; interrupted downloads restore as paused.
- Keep English default and 12 selectable UI languages, including Arabic RTL.

## Verified

- v1.3.0 application baseline: 114 Python tests plus frontend/i18n checks.

## Mobile availability

No mobile application is bundled in this Web v1.3.0 release. The [v1.4.0-alpha.1 source preview](v1.4.0-alpha.1.md) adds an Android source project and a limited on-device WeChat developer package. Android debug APKs exist locally but are excluded from public attachments pending their native dependency distribution audit.

iOS standalone app: **not yet implemented; no signed build or TestFlight/App Store link**.

WeChat Mini Program: **no live entry or release QR code**. The separate preview currently supports direct HTTPS MP4 links, not platform share-page extraction.

This release must not be described as a four-platform release. Future platform artifacts will be attached only after actual implementation, build, signing where applicable, and validation.

## Operation and known limits

Read the installation guide included as `README.md` in each deployment archive. Personal local use starts with `python start.py`; server prerequisites are Python 3.11+, FFmpeg/FFprobe, and Deno 2.3+ or Node.js 22+ for YouTube.

Files no longer expire automatically. Use the original browser cookie to recover jobs after restart and delete unwanted tasks to reclaim server storage. A configured access key and a platform account may need reauthentication. Source support for resumption is not guaranteed; merging is cancellable but not pausable.

Only Bilibili local member login is integrated. Source permissions, region, DRM and platform changes still apply. Only use media you own or are authorized to download.
