# Platform integrations / 平台接入

Source update: 2026-09-20. These integrations are in the current source tree.
The existing alpha.2 Release attachments are earlier builds. Use the current source
or a PC package generated by the current website deployment to use the changes.

## Added integrations

Web and the Android engine adapter now route these nine additional platforms to
dedicated yt-dlp extractors. No generic extractor or remote parsing service is enabled.

| Platform | Accepted page / share hosts | Dedicated extractor |
| --- | --- | --- |
| 抖音 / Douyin | `douyin.com`, `v.douyin.com`, `iesdouyin.com/share/video/...` | Douyin |
| 小红书 / Xiaohongshu | `xiaohongshu.com/explore/...`, `/discovery/item/...`, `xhslink.com` | XiaoHongShu |
| 微博 / Weibo | `weibo.com`, `m.weibo.cn`, `t.cn` | Weibo, WeiboVideo |
| 西瓜视频 / Ixigua | `ixigua.com`, `v.ixigua.com` | Ixigua |
| AcFun | `acfun.cn/v/ac...` | AcFunVideo |
| 新片场 / Xinpianchang | `xinpianchang.com/a...` | Xinpianchang |
| TED | `ted.com/talks/...`, TED embedded talks | TedTalk, TedEmbed |
| Pinterest | `/pin/...` on `pinterest.com`, `.jp`, `.co.uk`, `.ca`, `.de`, `.fr`, `.com.au`; `pin.it` | Pinterest |
| Niconico / ニコニコ動画 | `nicovideo.jp/watch/...`, `/shorts/...`, `nico.ms` | Niconico |

The original ten integrations remain: YouTube, X / Twitter, TikTok, Instagram,
Facebook, Vimeo, Bilibili, Dailymotion, Reddit and Twitch. **TikTok and Douyin are
separate integrations.** The UI now lists 19 platforms.

Only single videos are in scope. Image-only pins/posts, playlists, channels, live
recording, protected media and new account-login integrations are not added.
Share links are expanded inside the existing network guard and the final URL is
validated again. Xiaohongshu access parameters are preserved. Unresolved sharing
links return an error asking for the full video page rather than silently failing.

## Evidence and limitations / 验证边界

- Automated routing tests select each dedicated extractor from the installed
  yt-dlp engine. They also check malicious lookalike domains, short redirects,
  access-parameter preservation, complete Ixigua video IDs, and matching Web/Android
  and portable-client platform domains.
- The browser preview verifies 19 actual decoded, locally embedded icons; English,
  Chinese and Arabic switching; desktop, dark mode and a 320px platform modal with
  no horizontal overflow. This is UI evidence, not live downloading evidence.
- Public metadata-only checks used the upstream extractors' test URLs. The Douyin
  sample requested fresh cookies. The other eight samples were blocked by the
  existing network guard because this test environment resolved their connections
  to non-public addresses. Retrying without changing the guard did not resolve it.
  **No newly added platform completed live metadata acceptance in this environment.**
  No account credentials or full third-party videos were obtained for this check.
- The subsequent local VPN fix enables an explicit loopback proxy for Fake-IP
  environments. A public X sample passed live metadata analysis afterward; the
  nine new platforms were not rechecked. [Setup](LOCAL_PROCESSING.md#using-an-existing-local-vpn-proxy)
  and [validation details](TESTING.md).
- Only Bilibili has the existing Web account connection flow. The new integrations
  do not import cookies, log users into other sites, remove platform checks or relay
  video traffic through the publisher's website. A public URL can still require a
  platform session, permission, a particular region or an extractor update.
- Android source shares the engine policy. This update does not by itself certify
  an Android APK, phone/background behavior or live-platform compatibility.
- The WeChat Mini Program remains a local direct-MP4 preview. Shared domain
  validation is not a Mini Program platform parser. iOS remains deferred.
- Kuaishou and WeChat Channels are not added to the advertised list: there is no
  matching dedicated extractor in the installed engine. The upstream Kuaishou
  support request is still open at the time checked.

Upstream evidence: [extractor support list](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md),
[Kuaishou support request](https://github.com/yt-dlp/yt-dlp/issues/14010).
Inclusion in the upstream list is not a guarantee that a current link works.

## Logos and packaging

All 19 cards and the homepage's quick-source chips use actual official website
icons. Images keep their original colors and bytes, with a 44px card badge and a
32px image. Narrow screens use one column instead of shrinking the icons or text.
The Web/PC build and offline preview include the images and preserve binary bytes.
See [asset rights and provenance](ASSETS.md#platform-icons).

To try the new backend rules, start a fresh local service from the updated source;
an already-running service may still have the previous Python module loaded.
