ClipNest에서 원본 형식을 선택하고 재생 시간과 예상 크기를 확인한 뒤 다운로드를 승인하세요. 진행 상황과 예상 남은 시간을 확인하고, 원본 사이트가 지원하면 일시 중지와 재개를 할 수 있습니다. 취소하면 캐시가 삭제됩니다.

![자체 제작 영상의 화질 선택](../images/desktop-20260920.png)

인터페이스 미리보기입니다. 설치 없이 프로젝트의 자체 제작 애니메이션을 체험할 수 있습니다. 실제 플랫폼 링크는 분석하지 않으며, 데모 성공이 플랫폼 다운로드를 보장하지 않습니다.

## 내 기기에서 처리하고 저장

PC에 로컬 구성 요소를 설치하고 실행하면 웹사이트가 환경을 확인하고 전체 도구를 엽니다. 분석, 영상 전송, 병합은 사용자 PC에서 수행되며 ClipNest 웹사이트는 영상 트래픽을 중계하지 않습니다.

## 19개 플랫폼을 한곳에서

소스에는 19개 플랫폼의 전용 추출기와 공식 아이콘이 포함되어 있습니다. 최근 추가된 9개 플랫폼의 실제 링크 검증은 모두 완료되지 않았습니다. 이용 가능 여부는 권한, 지역, 플랫폼 변경에 따라 달라집니다.

## 모바일 버전의 현재 상태

Android 개발 미리보기에는 기기 내 엔진이 포함되어 있지만 공개 APK 배포와 실제 기기 검증은 아직 완료되지 않았습니다. WeChat 미니프로그램 미리보기는 MP4 직접 링크만 처리합니다. iOS 앱은 아직 제공하지 않습니다.

ChatGPT와 Codex를 이용한 OpenAI Vibe Coding으로 개발했습니다. 독립 프로젝트이며 OpenAI의 공식 제품이 아닙니다.

본인이 소유하거나 사용 허가를 받은 콘텐츠만 다운로드하세요. DRM을 해제하지 않습니다.
