# Requirements and product evolution / 原始需求与产品演进

This document records the user's original request, later changes, and the implemented v1.3.0 scope. It is an edited product history, not a raw conversation export. Earlier implementation choices are separated from user requirements.

本文整理用户实际需求及其演进；“已实现”表示当前代码行为，“已验证”只覆盖具体测试范围，不等于用户已最终验收全部平台。

## 1. Original request / 原始需求

> 做一个网站能在线解析X，Youtube，tiktok等主流视频网站的视频链接并下载的网站。可以选清晰度。

English: Build a website that analyzes and downloads video links from X, YouTube, TikTok, and other mainstream video platforms, with a choice of quality.

最初的核心交付是：网页输入链接、得到实际可用格式、选择清晰度、下载并保存文件。原始这句话没有指定框架、固定文件上限、文件保留时长或会员平台。这些不能事后写成原始要求。

## 2. User-driven changes / 后续需求与反馈

| 阶段 | 用户要求或反馈 | 实现与当前状态 |
| --- | --- | --- |
| 初始产品 | 解析主流视频网站并选择清晰度下载 | FastAPI + yt-dlp + FFmpeg，原生网页；接入 10 个平台解析器；真实清晰度选项与文件保存 |
| 权限与会员 | 询问没有下载按钮的视频能否下载；已有会员时能否登录以获得高清 | 下载可行性取决于源站返回与权限，不由按钮有无单独决定；第一阶段加入 B站扫码登录，其他平台会员登录未接入，真实会员高清仍待验收 |
| 手机一致性 | 确认手机实现程度，以及与 Windows 端是否一致 | 使用同一套响应式网页与服务端；修正手机字体、触控区、二维码保存/返回检查；不是独立手机 App；普通手机网络入口仍待验证 |
| 固定限制 | 明确要求“无论是多大”都交给用户确认，不要固定临时文件大小限制 | 移除固定文件/临时空间、时长和总下载时间限制；每次下载先确认；保留实际磁盘不足保护和并发控制 |
| 连接提示 | 后端未连接、本机限制等提示让人误解为浏览器不允许下载 | 解释启动服务、离线预览与部署模式的差别；连接状态与错误码提供对应提示；默认会员模式仍限本机回环，LAN/Docker 需关闭该模式 |
| 媒体信息 | 帧率与音频编码显示“未知”，希望能取到 | 加入有预算的元信息取样探测，区分未知音轨与明确无音轨；探测失败不阻断解析，不伪造值 |
| 国际化 | 默认英文，可选择主流语言 | 12 种语言，记忆选择，阿拉伯语 RTL；菜单、任务、确认、登录、帮助及错误提示同步切换 |
| 评审反馈 | 要求查看 Fable 对代码和设计的最新评审 | 修正取消被显示为失败、错误码文案覆盖、本机访问模式说明及预览检查；评审结果不当作所有平台可用的证明 |
| 小窗口布局 | 输入框和 Paste 控件在空间不足时不合适，要求考虑最小尺寸 | 拆分输入与操作区；设置按钮最小尺寸和自动换行；检查分栏、320px 德语及阿拉伯语 RTL |
| 时间与生命周期 | 去掉 60 分钟保留及重启失效；下载前确认时长和可能耗时，下载中提示剩余时间 | v1.3.0 展示时长、大小和参考耗时；下载中提供实际进度 ETA；任务与文件持久化，不再定时清理 |
| 下载控制 | 用户取消即删除缓存，支持 Pause 与断点续传 | 暂停保留部分文件，继续时使用 yt-dlp 续传；取消先停止进程再清缓存；合并阶段仅可取消；源站不支持时可能重下 |
| 公开发布 | 将代码公开到 GitHub，介绍原始需求、变更与最终功能，并标注 OpenAI Vibe Coding | 整理中英文 README、需求演进、架构、操作、测试与变更记录；保留 MIT 许可及原创演示素材说明 |
| 发布结构 | 源码保留功能实现、需求说明、测试维护和环境说明；截图属于文档，成品使用 Release | 本地整理源码范围与 Web 部署包构建方式；生成预览、重复启动入口不提交，安装包不混入源码 |
| 独立手机 App | Android、iOS 在手机本地解析和下载，不依赖自建服务 | Android 端侧工程与预览 APK 已实现；iOS 暂缓，抽出可复用界面、数据协议和纯逻辑。真机和逐平台实链验证仍须完成 |
| 微信小程序 | 新增微信小程序版本 | 用户明确要求完全手机端运行。已实现 MP4 直链元信息与本机下载预览；平台分享链接解析与分轨合并未完成，不使用远程服务替代 |

## 3. Decisions reversed during development / 明确移除的旧行为

| 早期实现选择（不是原始要求） | 用户决定后的行为 |
| --- | --- |
| 临时文件达到固定上限就停止并清理 | 不设固定大小上限；先告知并由用户确认，只在实际磁盘不足等错误时停止 |
| 完成文件保留 60 分钟 | 文件保留到用户取消或删除任务 |
| 服务重启导致任务索引失效 | 任务元数据写入磁盘；重启后已完成文件继续可用，未完成任务暂停等待继续 |
| 下载主要只有进度与取消 | 增加剩余时间、暂停、继续与保留检查点的错误重试 |
| 中文默认界面 | 英文默认，用户手动选择 12 种语言之一 |

旧环境变量 `MAX_FILE_MB`、`MAX_STORAGE_MB`、`MAX_DURATION_SECONDS`、`DOWNLOAD_TIMEOUT_SECONDS`、`FILE_TTL_SECONDS` 不再控制当前行为。源站、网络、权限、存储空间仍可能导致失败。

## 4. Final workflow / 当前用户体验

**Paste → Analyze → Choose quality → Review duration and estimate → Confirm → Track / Pause / Resume → Save.**

下载预估不承诺完成时间：开始前按 1–10 MB/s 参考区间计算，进行中按实际进度更新；未知大小、额外音轨和合并阶段按其真实状态展示。取消任务清理服务器缓存；已经保存到浏览器设备的文件不会被删除。

任务跨重启恢复依赖原浏览器持有的 Cookie；切换浏览器或清除网站数据后没有账户恢复入口。会员凭据不持久化，服务重启后需重新登录。

## 5. Scope that must not be overstated / 尚未完成或未验证

- 已接入 10 个平台解析器，不代表 10 个平台全部实链已验收。
- B站会员登录路径已实现，不能据此承诺所有会员高清都可下载；其他平台会员登录未实现。
- 手机响应式界面已测试，普通手机的 LAN/公网访问和真实 App 授权仍待验证。
- 断点续传在本地真实 HTTP/HLS 样本中验证，不能保证所有源站、所有过期媒体地址都能续传。
- Docker、macOS、公网部署未完成实际验收；GitHub 发布是公开源码，不是提供在线服务。
- 不提供 DRM 解除、直播录制、批量播放列表、字幕或通用转码；移动预览不等于所有平台功能已验收。

## 6. Development attribution / 开发方式

**代码由 OpenAI Vibe Coding 开发，使用 OpenAI ChatGPT 和 Codex。** 用户负责提出目标、反馈使用问题与决定需求变化，AI 完成代码和文档的生成、修订及工具辅助验证。外部评审意见作为改进输入；实际测试结果与未验证范围见 [TESTING.md](TESTING.md)。

这是用户驱动的独立项目，不代表 OpenAI 官方发布或背书。AI 辅助开发与测试通过均不构成对质量、平台兼容性或安全性的无限保证。

## 7. 2026-09-17 移动开发决定

- 用户要求先推进 Web、Android、小程序，Android 同时考虑后续 iOS 共通性。
- Android 和小程序都必须在手机内解析、下载；不接受以远程解析服务替代独立运行。
- 用户明确接受 Android 客户端使用 GPL-3.0，独立的 Web 与共通 MIT 模块保留原许可。
- 用户暂时没有 Mac/Xcode 或 Apple Developer 会员；讨论过个人侧载，但本轮暂缓 iOS 实现。
- 小程序的直链范围是目前已完成部分，**不是用户已经同意放弃平台分享链接解析**。完整小程序目标仍有未完成项。
- GitHub 上传、公开 Release 仍须按用户要求在具体内容准备好后再次确认；开始开发不等于授权立即上传。
